How does this work?

You chat with the assistant on the right; it extracts a render proposal once it has channel + topic. Hit "Make this Short" and the job lands in the cloud queue. The laptop agent (your own Mac) leases the task, runs the existing pipeline (Kokoro/F5 TTS, Whisper, mflux/Z-Image-Turbo, ffmpeg compose) and uploads the finished mp4 to GCS. Cost target: under $10/month at low traffic.
