# Source of Truth

> Last updated 2026-05-23 (post-Q&A refactor).

For every concern: where the authoritative answer lives. If two places
disagree, the row tells you which one wins. README.md is excluded — it
drifts.

## When two sources disagree

The general policy:

1. **Code wins over docs.** Comments and docstrings drift; the
   function body is authoritative. CLAUDE.md repeats this as a
   working principle.
2. **Env-set values win over hardcoded defaults** when the worker
   actually runs in prod. The hardcoded defaults documenting
   `ytfactory-prod-v2` in `control/core/cloud_run.py:50` and
   `entrypoint.py:136,139` are stale; the env vars from `deploy.sh`
   set v3.
3. **YAML wins over docs.** Channel rules in
   `pipeline/channels/<channel>.yaml` override anything claimed in a
   README or learning doc.
4. **User-locked decisions in `onboarding-qa.md` win over inferred
   behaviour.** The 2026-05-22 brainstorm locked 8 operating
   principles + a 17-item attack set — those are source of truth for
   *intent*, even where the code doesn't yet match.
